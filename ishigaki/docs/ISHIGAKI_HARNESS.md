# 🏝️ Ishigaki Island Explorer — 리팩터링 하네스 (for Claude Code)

> 이 문서는 Claude Code가 기존 React + p5.js 프로젝트를 **대폭 변경**할 때 따르는 작업 지침서다.
> 목표: 이시가키지마 여행 기록을 **동물의 숲 느낌의 3D 섬**으로 표현하고, **캐릭터가 섬을 돌아다니며** 여행 장소를 둘러보게 만든다.
> 단계(Phase) 순서대로 진행하고, 각 Phase의 **완료 조건**을 만족해야 다음 단계로 넘어간다.

---

## 0. 작업 규칙 (항상 지킬 것)

1. **시작 전에 반드시 저장소를 탐색하고 보고**한다.
   - `package.json`의 p5 버전(1.x / 2.x), React 버전, 빌드 도구(Vite/CRA/Next)를 확인한다.
   - p5를 어떻게 붙였는지 확인한다 (`@p5-wrapper/react`, `react-p5`, 직접 `new p5()` instance mode 등).
   - 현재 섬(원기둥), 산(원뿔), 나무, 바다 그리드, 텍스트 "Ishigaki Island", 집/열쇠 아이콘이 어느 파일에 있는지 목록으로 정리한다.
2. 작업은 새 브랜치에서: `git checkout -b feat/ishigaki-island-shape`
3. Phase마다 커밋한다. 커밋 메시지 예: `feat(island): Ishigaki coastline polygon mesh`
4. **기존 UI(좌상단 집 아이콘, 열쇠 아이콘)와 기능은 유지**한다. 지우거나 동작을 바꿔야 하면 먼저 사용자에게 묻는다.
5. 새 라이브러리 추가는 최소화한다. 허용: `earcut`(삼각분할), 필요시 `zustand`(상태 공유). 그 외는 사용자에게 먼저 묻는다.
6. 매직 넘버는 `src/world/config.js`(또는 `.ts`)에 모은다. 크기·속도·색상은 나중에 조정하기 쉽게.
7. 각 Phase 끝에 `npm run dev`로 실행 확인 → 무엇이 바뀌었는지 짧게 보고.

```

│  └─ props.js             # 나무, 바위, 등대 등 장식
├─ data/
│  └─ places.json          # 여행 기록 (장소, 날짜, 사진, 메모)
├─ sketch/
│  └─ IslandSketch.js      # p5 instance-mode 스케치 (위 모듈 조립)
└─ components/
   ├─ IslandCanvas.jsx     # p5 마운트/언마운트 담당
   ├─ HUD.jsx              # 집/열쇠 아이콘(기존), 장소 이름 배너
   └─ PlaceCard.jsx        # POI 근접 시 여행 기록 카드
```

### React ↔ p5 경계 규칙
- **p5는 캔버스(3D 월드)만**, **React는 DOM UI만** 담당한다. 텍스트 팝업·카드는 p5 `text()`가 아닌 React로 띄운다.
- p5 스케치는 `useEffect`에서 **한 번만** 생성하고 cleanup에서 `p.remove()`. React 리렌더링이 스케치를 재생성하면 안 된다.
- 스케치 → React: 콜백(`onNearPlace(placeId|null)`) 또는 zustand store.
- React → 스케치: ref로 넘긴 store를 스케치가 `draw()`에서 읽는다. props 변경으로 스케치를 재생성하지 말 것.

## Phase 1 — 이시가키 해안선 polygon 만들기 (1순위 · 핵심)

### 1-A. 해안선 데이터 확보 (아래 우선순위대로 시도)

**방법 1 (권장): 실제 지리 데이터**
- OpenStreetMap의 이시가키지마 해안선을 GeoJSON으로 받는다.
  - 사용자에게 overpass-turbo.eu 에서 아래 쿼리로 Export → GeoJSON 다운로드 요청 (샌드박스에서 외부 다운로드가 막혀 있을 수 있음):
    ```
    [out:json];
    way["natural"="coastline"](24.32,124.06,24.62,124.36);
    (._;>;);
    out body;
    ```
  - 또는 `place=island` + `name=石垣島` relation.
- `scripts/buildCoastline.mjs`를 만들어 GeoJSON → 단순화(Douglas-Peucker, 목표 **150~300개 점**) → `src/world/coastline.js`로 출력.
- 이시가키 대략 범위: 위도 24.33 ~ 24.61, 경도 124.07 ~ 124.35.

**방법 2: 참고 지도 트레이싱 도구**
- `?trace=1` 쿼리일 때 `docs/ref/ishigaki_map.png`를 반투명으로 띄우고 클릭하면 점이 찍히는 2D 트레이싱 모드를 만든다.
- 점 추가/되돌리기(Z)/드래그 수정/JSON 복사 버튼. 결과를 `coastline.js`에 붙여넣는다.
- 사용자가 직접 원하는 만큼 정밀하게 다듬을 수 있어서 가장 확실한 방법.

**방법 3 (임시 fallback): 아래 대략 좌표**

### 1-B. 좌표 변환 (`geo.js`)
```js
// 위경도 → 미터 (등장방형 근사, 섬 크기에서는 충분히 정확)
const LAT0 = 24.45, LON0 = 124.21;
x_m = (lon - LON0) * Math.cos(LAT0 * Math.PI/180) * 111320;
z_m = -(lat - LAT0) * 110540;   // 북쪽 = -z (화면 안쪽)
// 미터 → 월드 단위
x = x_m * WORLD_SCALE; z = z_m * WORLD_SCALE;
```
- 픽셀 좌표(fallback/트레이싱)라면: 중심을 원점으로, `y`를 `-z`로 뒤집어 같은 월드 크기로 정규화.
- **월드 크기 기준**: 섬 남북 길이를 `ISLAND_LENGTH = 2400` 월드 단위 정도로. 기준은 "캐릭터가 남쪽 시내에서 북쪽 히라쿠보 곶까지 걸어서 약 2~3분". `config.js`에서 조절 가능하게.
- 유틸 함수: `pointInPolygon(x,z)`, `distanceToCoast(x,z)`(가장 가까운 선분까지 거리), `closestPointOnCoast(x,z)`.

### 1-C. 섬 메시 (`terrain.js`)
현재 원기둥(`cylinder`)을 **해안선 모양의 계단식 섬**으로 교체한다. 동물의 숲처럼 층이 진 느낌:

| 층 | 만드는 법 | 색 (참고) |
|---|---|---|
| 모래 해변 | 해안선 polygon 그대로, 높이 0~4 | `#F2E3B3` |
| 잔디 1층 | 해안선을 안쪽으로 `BEACH_WIDTH`(약 40) 만큼 inset | `#7DBE5A` |
| 언덕 2층 | 더 안쪽 inset, 내륙 중앙부만 | `#6AAE4C` |
| 오모토산 | 산 위치(아래 POI 좌표) 중심 완만한 봉우리 | `#5E9E46` |

- 구현 추천: **격자 높이맵 방식**이 가장 유연하다.
  - 섬 bounding box에 `GRID_STEP`(≈12) 간격 격자 → 각 정점에서 `height(x,z)` 계산 → 섬 밖 정점은 바닷속(-10)으로.
  - `height(x,z)` = `distanceToCoast` 기반 계단 함수(층 사이를 짧은 경사로 smoothstep) + 산 가우시안.
  - 정점 색은 높이 구간으로 결정 → `p.buildGeometry()`(p5 1.8+) 또는 `p5.Geometry`로 **한 번만** 빌드해 캐싱. 매 프레임 재생성 금지.
- 대안(간단): 층마다 inset polygon을 `earcut`으로 삼각분할한 윗면 + 옆면 벽(extrude). 절벽 느낌은 이쪽이 더 동물의 숲 같다. 둘 중 결과가 더 나은 쪽을 선택해 보고.
- 해안 가장자리에 반투명 흰 띠(파도 거품)를 polygon 외곽에 살짝 띄운다.

### 1-D. 바다
- 현재 진한 파랑 체크 그리드 대신, 동물의 숲 톤의 **민트/청록 단색 평면** + 해안 근처는 밝은 얕은물 색(`#7FD6D0` → 먼바다 `#3FA9C9`).
- 얕은물 표현: 섬 polygon을 바깥으로 offset한 밝은 평면을 바다보다 살짝 위(+0.5)에 깐다.
- 간단한 물결: 셰이더 또는 `sin(time)` 기반 정점 높이 ±1.

## Phase 2 — 동물의 숲식 "둥근 지평선" 카메라

동물의 숲은 땅이 **통나무처럼 둥글게 휘어 보이는** 효과(rolling-log)를 쓴다. 실제 지구본처럼 섬을 구에 올리지 말고, **버텍스 셰이더로 카메라에서 멀어질수록 아래로 휘게** 한다.

### 2-A. 곡률 셰이더 (`curvedShader.js`)
```glsl
// vertex shader 핵심 (p5 WEBGL 기본 attribute/uniform 이름 사용)
attribute vec3 aPosition;
attribute vec3 aNormal;
attribute vec4 aVertexColor;   // 정점 색을 쓰는 경우
uniform mat4 uModelViewMatrix;
uniform mat4 uProjectionMatrix;
uniform float uCurve;          // 0.0002 ~ 0.0008 정도에서 조절
varying vec4 vColor;
varying vec3 vNormal;

void main() {
  vec4 viewPos = uModelViewMatrix * vec4(aPosition, 1.0);
  float d = viewPos.z;               // 카메라 앞쪽 거리 (음수)
  viewPos.y -= d * d * uCurve;       // 멀수록 아래로 → 둥근 지평선
  // 좌우로도 살짝 휘게 하려면: viewPos.y -= viewPos.x*viewPos.x*uCurve*0.3;
  gl_Position = uProjectionMatrix * viewPos;
  vColor = aVertexColor;
  vNormal = aNormal;
}
```
- p5 WEBGL의 y축은 **아래가 +** 이므로 실제 부호는 화면에서 확인 후 맞춘다 (지평선이 위로 솟으면 부호 반전).
- p5 2.x라면 attribute/uniform 이름과 `baseMaterialShader().modify()` 훅 방식이 다르다. 버전 확인 후 맞는 방식 사용.
- **섬, 바다, 나무, 캐릭터 모두** 같은 셰이더(또는 같은 곡률 공식)를 써야 물체가 땅에서 떠 보이지 않는다.
- 간단한 램버트 조명 + 따뜻한 환경광을 fragment shader에 넣어 동물의 숲 같은 부드러운 음영.

### 2-B. 3인칭 카메라 (`camera.js`)
- 캐릭터 뒤쪽 위에서 **고정된 각도로 내려다보는** 동물의 숲 시점: pitch ≈ 35~45°, 거리 ≈ 220, 높이 ≈ 160 (config).
- 카메라는 회전하지 않고 캐릭터 위치만 `lerp(0.08)`로 부드럽게 추적 (동물의 숲처럼 북쪽이 항상 화면 위).
- 선택: Q/E 또는 화면 버튼으로 45° 단위 회전 옵션.
- 원근 `perspective(fov≈50°)`. 지평선이 화면 상단 1/4쯤에 보이도록 `uCurve`와 pitch를 같이 조정.

## Phase 3 — 캐릭터가 섬을 돌아다니기

### 3-A. 캐릭터 모델 (`player.js` + `src/character/`)

> ⚠️ **이번 작업에서는 캐릭터 꾸미기 "틀(구조)"만 만든다.**
> 나중에 동물의 숲처럼 머리모양, 눈, 코, 입, 옷 등을 꾸미는 기능을 추가할 예정이다.
> 지금은 **파츠를 갈아끼울 수 있는 구조 + 파츠별 기본값 1개씩**만 구현한다.
> 여러 종류의 머리모양/눈/옷 디자인, 꾸미기 UI 화면은 **만들지 않는다.**

- 외부 모델 없이 p5 기본 도형으로 **2~2.5등신 치비** 캐릭터 (큰 머리, 작은 몸통, 짧은 팔다리).
- 발 밑에 반투명 원형 그림자(동물의 숲 느낌의 핵심).

```
   ├─ bottom.js         # 하의       — 기본값 1개만 ("shorts")
   ├─ shoes.js          # 신발       — 기본값 1개만 ("sneakers")
   └─ accessory.js      # 액세서리   — 기본값 "none" (모자, 안경, 꽃핀 자리만 마련)
```

#### 외형 설정 스키마 (`characterConfig.js`)
```js
export const defaultCharacter = {
  skinColor: "#FCE3CF",
  hair:      { style: "short",  color: "#D9D4CF" },
  eyes:      { style: "round",  color: "#2B2B2B" },
  nose:      { style: "dot" },
  mouth:     { style: "smile" },
  cheeks:    { style: "pink" },
  top:       { style: "tshirt", color: "#6FBF5A" },
  bottom:    { style: "shorts", color: "#4A6FA5" },
  shoes:     { style: "sneakers", color: "#F2C14E" },
  accessory: { style: "none" }
};
```

#### 구조 규칙
- 각 파츠 파일은 `export const styles = { short: (p, opts) => { ... } }` 형태의 **스타일 레지스트리**로 만든다. 새 디자인 추가 = 함수 하나 추가.
- 파츠 함수는 **자기 기준점(머리 중심, 몸통 중심 등) 기준 로컬 좌표**로만 그린다. 위치·회전·걷기 애니메이션은 `drawCharacter`가 담당.
- 얼굴 파츠(눈/코/입/볼)는 머리 앞면에 붙는 작은 도형 또는 평면 텍스처 중 하나로 통일. 나중에 표정 변경이 쉽도록 **얼굴 파츠는 머리와 분리**해서 그린다.
- 없는 스타일 id가 들어오면 기본값으로 대체하고 콘솔 경고 (에러로 멈추지 않게).
- 외형 설정은 store에 두고, 나중에 React 꾸미기 화면이 이 값을 바꾸면 **스케치 재생성 없이** 다음 프레임부터 반영되게 한다.
- 저장은 아직 구현하지 않는다. (나중에 localStorage 또는 서버 저장 예정)

#### 3-A 완료 조건
- [ ] 기본 캐릭터가 파츠 조합으로 그려진다.
- [ ] `characterConfig.js`에서 색상을 바꾸면 바로 반영된다.
- [ ] 아무 파츠 파일에 스타일 함수를 하나 추가하고 설정 id만 바꾸면 모양이 바뀐다 (구조 검증용으로 확인만 하고, 추가한 테스트 스타일은 지운다).

### 3-B. 조작
- 키보드: WASD / 방향키. Shift = 달리기(속도 ×1.8).
- 모바일: 화면 좌하단 가상 조이스틱 (React DOM 오버레이, 값만 store로 전달).
- 이동 방향은 **카메라 기준**(화면 위 = 앞).
- 대각선 정규화, 가속/감속(관성)으로 미끄러지듯 부드럽게.
- 캐릭터는 이동 방향으로 부드럽게 회전 (각도 lerp, 최단 회전 방향).

### 3-C. 지형 따라 걷기 + 충돌
- 매 프레임 `y = height(x, z)` 로 캐릭터를 지면에 붙인다 (층 사이 경사에선 부드럽게 오르내림).
- **섬 밖(바다)으로 못 나가게**: 다음 위치가 `pointInPolygon` 밖이거나 `distanceToCoast < 6`이면 이동 벡터를 해안선 접선 방향으로 투영해 **벽을 따라 미끄러지게** 한다 (그냥 멈추면 답답함).
- 나무·바위·건물은 원형 콜라이더로 밀어내기.
- 선택(나중): 너무 높은 절벽은 막고 경사로로만 오르기 (동물의 숲 언덕).

### 3-D. 걷기 애니메이션
- 걸을 때 몸 위아래 bobbing(`sin(t*12)*2`), 팔다리 앞뒤 스윙, 멈추면 숨쉬기(살짝 스케일).
- 걸을 때 발밑에 작은 먼지 파티클 (잔디 위: 연두, 모래 위: 베이지).

### 3-E. 시작 위치
- 이시가키 공항(파이누시마 이시가키 공항) 근처에서 시작 — 동물의 숲 비행장에서 시작하는 것처럼. 비행기 아이콘 소품 배치.

## Phase 5 — 동물의 숲 분위기 마감

- 소품: 야자수(줄기 + 잎 4~6장, 바람에 살랑), 둥근 활엽수(구 2~3개 겹침), 꽃 무리(작은 색 점들), 바위.
  - 해변 근처엔 야자수, 내륙엔 활엽수, 산엔 밀도 높게. polygon 안 랜덤 배치(시드 고정)하되 POI·길 근처는 비움.
  - 많은 소품은 `buildGeometry`로 묶어 draw call 줄이기.
- 길: 공항 → 시내 → 해안도로처럼 섬을 도는 흙길(베이지 띠)을 해안선 inset 경로로 그린다 (실제 이시가키 390번 도로처럼 섬을 둘러감).
- 색감: 채도 높고 밝은 파스텔. 하늘은 위→아래 하늘색 그라데이션.
- 선택: 하루 시간대(낮/노을), 발소리·파도 소리(사용자 상호작용 후 재생).

## 실행 순서 요약
```
0. 저장소 탐색 → 보고 → 브랜치 생성
1. 해안선 polygon (fallback 먼저 → 실제 데이터로 교체) → 계단식 섬 메시 → 바다
2. 곡률 셰이더 + 3인칭 카메라
3. 캐릭터 + 이동 + 해안 충돌 + 지형 높이 따라가기
4. POI 데이터 + 근접 카드 + 지역 배너
5. 소품/길/색감 마감
각 단계: 실행 확인 → 완료 조건 체크 → 커밋 → 짧은 보고
```
